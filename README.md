# Napęd wentylatora — projekt PKM

Projekt konstrukcyjny napędu wentylatora wykonany w ramach przedmiotu
Podstawy Konstrukcji Maszyn (PKM).

## Zawartość

| Plik | Opis |
|---|---|
| `design-calculations.pdf` | Dokumentacja obliczeniowa projektu |
| `assembly-drawing.pdf` | Rysunek złożeniowy |
| `driven-wheel-drawing.pdf` | Koło bierne (rysunek wykonawczy) |
| `shaft-drawing.pdf` | Wał (rysunek wykonawczy) |
| `fan-assembly.stl` | Model 3D złożenia (STL) |

## Technologie

- Modelowanie 3D / CAD
- Rysunek techniczny
- Obliczenia wytrzymałościowe (wał, łożyska, połączenia)
