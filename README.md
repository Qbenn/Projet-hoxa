# Napęd wentylatora — projekt PKM

Projekt konstrukcyjny napędu wentylatora wykonany w ramach przedmiotu
Podstawy Konstrukcji Maszyn (PKM).

## Zawartość

| Plik | Opis |
|---|---|
| `PKM6_nowy_ok-5.pdf` | Dokumentacja obliczeniowa projektu |
| `zlozenieJP.pdf` | Rysunek złożeniowy |
| `BierneJP.pdf` | Koło bierne (rysunek wykonawczy) |
| `wałJP.pdf` | Wał (rysunek wykonawczy) |
| `assembly1 — kopia.stl` | Model 3D złożenia (STL) |

## Technologie

- Modelowanie 3D / CAD
- Rysunek techniczny
- Obliczenia wytrzymałościowe (wał, łożyska, połączenia)
